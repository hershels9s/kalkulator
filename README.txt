KALKULATOR HARGA

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka index.html di browser (Chrome/Edge/Firefox).
3. Tidak membutuhkan hosting, database, atau internet.

Fitur:
- Pencarian kategori/item.
- Tambah Lokal/Import ke pesanan.
- Hitung total otomatis.
- Ubah nama kategori.
- Tambah/hapus kategori.
- Ubah nama item.
- Ubah harga Lokal/Import.
- Tambah/hapus item.
- Reset ke data awal.
- Perubahan tersimpan otomatis di localStorage browser.

Catatan:
Harga disimpan sebagai angka Rupiah. Untuk kategori Performance, harga Lokal dan Import memang sama sesuai data yang diberikan.
